    Class ColorFilter

    ColorFilter for color transformations. Mirrors CanvasKit.ColorFilter API.

    Remarks

    • Matrices operate in the canvas's working color space (sRGB, P3, or linear)
    • Filters are immutable and safe to reuse across draws
    • Input arrays are copied - safe to mutate after creation

    🧪 Not in the HTML Canvas standard.

      Create a color filter of the given kind.

      The kind names the transform and the remaining arguments are the ones that kind takes, matching the Make method of the same name. Where those return null for arguments Skia rejects, the constructor throws instead.
