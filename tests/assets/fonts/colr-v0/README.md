# COLR version 0 fixture

`COLR-palettes-test-font.ttf`, from web-platform-tests, `css/css-fonts/resources/COLR-palettes-test-font.ttf`, unmodified. A `COLR` table of version 0, layers of solid colour from `CPAL`, over `glyf` outlines.

The font is derived from Ahem, which its own name table puts in the public domain, with the Creative Commons Zero declaration where public domain ownership is not recognised (`http://dev.w3.org/CSS/fonts/ahem/COPYING`).
