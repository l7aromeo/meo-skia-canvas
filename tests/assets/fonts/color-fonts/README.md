# color-fonts fixture

`samples-glyf_colr_1.ttf`, from github.com/googlefonts/color-fonts at commit
`0046ea4c3b69e9fbbe464c2594816894e3aa5e4b`, `fonts/samples-glyf_colr_1.ttf`,
unmodified, under the Apache License 2.0 in `LICENSE`, that repository's own.
Its glyphs are `glyf` outlines painted by a `COLR` table of version 1, with
their colours in `CPAL`: a colour font whose colours do not come from the
paint the text is drawn with. It maps `a`, `c` to `g`, `i`, `l` to `p`, `r`
to `t`, `y` and the space.

It stands in for a COLRv1 emoji font. This tree carries none, and macOS's
own colour emoji, Apple Color Emoji, is an `sbix` font.

`test_glyphs-glyf_colr_1_variable.ttf`, from the skia-bindings 0.156.0 crate's `skia/resources/fonts/`, where Skia keeps it for its `colrv1` GM. Skia notes it was generated by googlefonts/color-fonts' `config/test_glyphs-glyf_colr_1.py` (`skia/gm/colrv1.cpp`), under the same Apache License 2.0. Its name table versions it `2024-01-18T17:23:48.602416`. Its 221 code points, from U+F0100 to U+FE007, each name a glyph testing one part of `COLR` version 1: every gradient and its extend modes, the transforms, the clip boxes, the 28 composite modes, the foreground colour, and a glyph-in-glyph nesting. Its 44 axes vary every one of those, which is what the varied reference exercises -- see `tests/assets/images/colr`.
