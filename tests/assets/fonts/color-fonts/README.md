# color-fonts fixture

`samples-glyf_colr_1.ttf`, from github.com/googlefonts/color-fonts at commit
`0046ea4c3b69e9fbbe464c2594816894e3aa5e4b`, `fonts/samples-glyf_colr_1.ttf`,
unmodified, under the Apache License 2.0 in `LICENSE`, that repository's own.
Its glyphs are `glyf` outlines painted by a `COLR` table of version 1, with
their colours in `CPAL`: a colour font whose colours do not come from the
paint the text is drawn with. It maps `a`, `c` to `g`, `i`, `l` to `p`, `r`
to `t`, `y` and the space.

It stands in for a COLRv1 emoji font. This tree carries none, and macOS's
own colour emoji, Apple Color Emoji, is an `sbix` font.
