meo-skia-canvas

The HTML Canvas 2D API on Skia, for Node and Rust.

Google's Skia underneath, so output matches Chrome's <canvas> closely — and then a good deal a browser canvas cannot do. One implementation, two surfaces: the same objects and the same calls from Rust, in Rust's own spelling, argument for argument.

JavaScript API reference — v5.8.0 Generated from the type declarations the package ships. Always at latest/.

What you get

import { Canvas } from "meo-skia-canvas";

let canvas = new Canvas(1920, 1080, {
    colorType: "RGBAF16", // composites in float, not just reads back in it
    colorSpace: "display-p3", // or rec2020, rec2020-pq, srgb-linear, ...
  }),
  ctx = canvas.getContext("2d");

ctx.fillStyle = "oklch(70% 0.28 25)"; // outside sRGB, and kept
ctx.fillRect(0, 0, 1920, 1080);

await canvas.toFile("out.png"); // 16 bits a channel, tagged P3

  • Float compositing

    RGBAF16 and RGBAF32 composite in float rather than merely reading back in it, so stacked translucent layers do not accumulate rounding error.

  • Wide gamut and HDR transfer functions

    Fifteen names across eight spaces — sRGB, Display P3, Rec. 2020, HDR10 (PQ), HLG and linear variants. A canvas composites in the space you name and exports tagged with it.

  • CSS Color 4, and OkLab gradients

    oklch(), lab() and color() parse wherever a colour is taken, and a gradient interpolates in the space you choose — oklab holds lightness where sRGB goes muddy in the middle.

  • Eleven export formats

    PNG, JPEG, WebP, GIF, APNG, TIFF, ICO, BMP, AVIF, PDF and SVG. Pages are frames: the four formats that carry a clock write animations, and an animation read back reports its own frames and delays.

  • Typography that goes past fillText

    Variable font axes, OpenType features, word wrap with per-line metrics, and a ParagraphBuilder for rich text with mixed styles, per-run shadows and hit testing.

  • GPU rendering

    Metal on macOS, Vulkan elsewhere, chosen per canvas. canvas.engine reports which backend took it, the adapter, and why the GPU was declined when it was.

  • Path geometry and filters

    Boolean operations, trim, interpolate, 3D projection and vector textures, plus the CSS filter set and CanvasKit's ColorFilter, ImageFilter, MaskFilter and Shader.

  • On-screen as well as off

    Window and App give a browser-like event loop, from Rust as well as Node.
