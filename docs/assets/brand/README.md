# Branding

The two hero banners on `README.md`, `docs/index.md` and `docs/node.md`.

Drawn by `docs/generate/brand.js` and redrawn by `just docs-assets`, like
everything under `../api`. The banners that were here before were Skia
Canvas's own — samizdatco's wordmark and diamond mark, inherited with the
fork, describing a library for Node.js alone. Neither the mark nor the
sentence was ours to fly.

The mark is one cubic Bézier with its control handles showing, which is both
what this library draws and the shortest way to say so.
