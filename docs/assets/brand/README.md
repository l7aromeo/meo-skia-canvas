# Branding

The two hero banners on `docs/index.md` and `docs/node.md`.

Hand-authored artwork, not drawn by this library, and deliberately outside
`just docs-assets`. They live here rather than beside the API illustrations
so the split says which is which: everything under `../api` is regenerated
from `docs/generate`, everything under `../gallery` from `examples/node`,
and everything here is edited by hand and stays as it is until someone
draws a new one.
