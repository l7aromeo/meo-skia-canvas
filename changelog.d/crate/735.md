### Fixed

- **A gradient mixed in `GradientColorSpace::ProphotoRgb` follows CSS Color 4's curve, linear below 16/512, where it drew dark ramps up to 4 levels off; an SVG export draws it as an image, since SVG's own gradient mixes in sRGB.** ([#753](https://github.com/l7aromeo/meo-skia-canvas/issues/753))
- **On Windows, a DLL linking the crate stays loaded for the life of the process once the crate starts a thread, so a pool thread parked in its code no longer crashes the process after the DLL is unloaded.** ([#735](https://github.com/l7aromeo/meo-skia-canvas/issues/735))
