### Fixed

- **A canvas holding colour glyphs or gradients, drawn with `drawImage` into a GPU canvas, lands on the bytes a CPU canvas stores for it.** ([#795](https://github.com/l7aromeo/meo-skia-canvas/pull/795), [#703](https://github.com/l7aromeo/meo-skia-canvas/issues/703))
- **Glyphs that overlap under `multiply` through `luminosity`, on a canvas drawn into a GPU canvas with `drawCanvas()` or inside a `saveLayer()` on a GPU canvas, land the bytes a CPU canvas draws.** ([#795](https://github.com/l7aromeo/meo-skia-canvas/pull/795), [#764](https://github.com/l7aromeo/meo-skia-canvas/issues/764))
- **Text a GPU canvas draws in memory -- a gradient-filled run under a filter, or any text under a filter on a float canvas -- takes the canvas's `textContrast` and `textGamma`, not Skia's defaults.** ([#795](https://github.com/l7aromeo/meo-skia-canvas/pull/795), [#785](https://github.com/l7aromeo/meo-skia-canvas/issues/785))
- **On a GPU canvas a shape filled or stroked with a gradient has the anti-aliased edge a CPU canvas gives it, so its `shadowBlur` shadow, `blur()` and `drop-shadow()` are those of the edge it draws.** ([#795](https://github.com/l7aromeo/meo-skia-canvas/pull/795), [#766](https://github.com/l7aromeo/meo-skia-canvas/issues/766))
